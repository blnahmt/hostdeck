# Delete Your Data

Hostline RD has no account, so there is no account to delete. All data the app keeps is stored only on your computer.

## How to remove all data

1. Uninstall Hostline RD.
2. Delete the folder `%AppData%\HostlineRD`. To open it, press **Win+R**, type `%AppData%` and press **Enter**.

This folder contains your connections, settings, history, thumbnails, saved SSH host keys and saved (encrypted) passwords.

Encrypted export files you created yourself are not deleted automatically; remove them wherever you saved them.
